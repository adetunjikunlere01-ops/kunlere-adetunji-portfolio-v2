# Kunlere Adetunji O. — Architecture Portfolio

Static HTML, CSS and JavaScript portfolio.

## Local preview
Open `index.html` in a browser, or serve this folder with any static file server.

## Deployment
Suitable for GitHub Pages, Netlify or Vercel static deployment. No build command is required; set the project root to this folder and leave the build command empty.

## Notes
- `index.html` contains the project data and interactions.
- `styles.css` contains the visual system and responsive rules.
- `assets/` contains project spreads and the portfolio PDF.
- Confirm the production domain before adding canonical URL and sitemap entries.
